# App Prototype

This is a clickable UI concept for the first internal Gruber AI Procurement Intelligence System release.

## Run locally

From the package root:

```bash
php -S localhost:8080
```

Open:

```text
http://localhost:8080/app-prototype/index.php
```

The prototype uses sample data and has no database connection. It demonstrates the navigation, modules, AI finding queue, dashboard, supplier scorecards, inventory views, projects, savings pipeline and reports.
