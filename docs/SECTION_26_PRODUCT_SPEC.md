# Section 26 — Enterprise Work Management, Exception Command Center & Automation Rules

Section 26 is the supervised operating layer connecting the Section 24 entity hierarchy to Section 25 process orchestration. It provides a unified queue for work generated by procurement, supplier, inventory, finance, process, approval, and data-quality records.

## Operating principles

1. Canonical modules remain authoritative for business status and financial records.
2. Work items are supplemental coordination records linked to source evidence.
3. Originating operating entity controls visibility; shared-service assignment does not grant sibling-company access.
4. Every action is permission-checked, company-scoped, evidenced, and recorded.
5. Automation proposes or creates bounded work only through published, locked, replay-safe rules.
6. Agent recommendations remain supervised and cannot directly execute canonical changes.

## Primary workspaces

- Command Center
- My Work
- Team Queue
- Exception Command Center
- Automation Rules
- Operational Analytics
- Governance History

## Core metrics

Open work, personal workload, critical work, overdue work, blocked work, pending reviews and approvals, SLA compliance, response time, resolution time, automation success, escalation levels, workload by company, workload by user, source recurrence, and aging.
