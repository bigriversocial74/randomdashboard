# Scroll Pitch Presentation

The pitch page is a self-contained PHP/CSS/JavaScript presentation based on the Procurement Transformation Launch Plan.

## Run locally

From the package root:

```bash
php -S localhost:8080
```

Open:

```text
http://localhost:8080/pitch/index.php
```

No database or JavaScript framework is required. The animation layer uses CSS and `IntersectionObserver`.
