# EV Storage Website Template

A responsive, image-led landing page modeled after the supplied EV Storage concept.

## Run locally

```bash
php -S 127.0.0.1:8080
```

Then open `http://127.0.0.1:8080`.

## Structure

- `index.php` — complete landing page
- `assets/css/site.css` — responsive visual system and layouts
- `assets/js/site.js` — navigation, reveal, progress and parallax effects
- `assets/images/` — separate generated production assets

The membership form is visual only and does not submit data.
